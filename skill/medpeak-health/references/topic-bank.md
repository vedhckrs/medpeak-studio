# Topic bank

70 topic ideas for MedPeak Health, researched on 2026-11-17 on the Windows PC. The owner wants to
start with the first 15.

## How this list was made, and what it does not prove

- **Search demand.** YouTube's own search suggestions were pulled for 15 question stems
  ("what happens if you", "why do you get", "what causes", "is it bad to" and so on), each with every
  letter a to z, for India, the US and the UK. About 8,000 suggestions. A topic is here because people
  type it.
- **Proof of views.** For topics 1 to 14 the first page of YouTube results was read and the videos
  over 1 million views were counted. Topics 15 to 70 were **not** checked this way (the owner asked for
  the list fast).
- **Not measured: click-through rate.** CTR only exists in the channel's own YouTube Studio. The
  titles below copy the words people type, which is the best outside stand-in.
- **Not done: sources.** No topic here has been researched. Every one is a candidate until its
  sources are read (`medical-accuracy.md`). A topic with no solid source is dropped, never bent to fit.
- **Not done: overlap check.** The list was not compared with `plans/month-1-2026-11-18.md` on
  `feat/toons` or with the videos already made. Check before starting a topic.

## How to use it

1. Take the next topic whose status is `open`, top to bottom.
2. Before any work, set its status to `taken (machine, date)` and push, so the other machine does not
   make the same video.
3. When it is made, set the status to the video's slug.
4. Topics marked **care** need the exact wording of the named kind of source, never memory.
